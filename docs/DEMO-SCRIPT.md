# Demo video script (under 5 minutes)

All data is fictional (Brightloop). No real company, people or numbers.

| Time | Scene | Say / show |
|---|---|---|
| 0:00–0:30 | Problem | "Marketing's board slide says churn is 4.1%. Finance says 6.3%. The meeting stalls on whose number is right." Show the Jira request. |
| 0:30–1:15 | Jira panel | The OneNumber panel flags two churn definitions: a 30 vs 90 day window, and trial accounts included vs excluded. The canonical owner is named. |
| 1:15–1:45 | Reconcile | One click creates a linked task for the data team with every difference listed. |
| 1:45–2:30 | Confluence | The board-deck page byline flags disputed metrics. The metric card shows the canonical definition and contributors from Teamwork Graph. |
| 2:30–3:30 | Rovo + MCP | Metric Steward answers "Which churn should I use for the board?". Then a Rovo Studio agent uses the OneNumber MCP tools (bonus segment). |
| 3:30–4:15 | Health page | Disputed / trusted / unverified overview; edit a definition and watch it update automatically. |
| 4:15–4:45 | How it works | Rule-based engine, no hallucinated differences; Jira + Confluence + Rovo + Teamwork Graph; human approves every task. |
